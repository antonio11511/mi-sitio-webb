# Mi Sitio Web Personal — Antonio Vergara Pineda

Portafolio web personal desarrollado como proyecto de aprendizaje de Sistemas Informáticos.

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Estructura
- `index.html`: estructura y contenido del sitio.
- `css/estilos.css`: diseño visual y responsive.
- `js/script.js`: menú móvil, año automático y formulario.
- `img/`: carpeta destinada a fotografías y evidencias.
- `README.md`: documentación.

## Antes de publicar
1. Reemplazar el avatar por una fotografía personal si se desea.
2. Cambiar el correo y enlaces de redes por los datos reales.
3. Agregar evidencias reales de los tres proyectos.
4. Probar el sitio en computador, tablet y celular.
5. Subir la carpeta a un repositorio de GitHub.
6. Activar GitHub Pages para obtener el enlace público.
